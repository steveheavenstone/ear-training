Headphones or speakers both work. On Speakers I shorten my note, wait until it has fully decayed before opening the mic, and ask the browser to cancel my own output — so my note can't be scored as yours. Headphones are still the cleanest option, and the only one that fully removes the risk. The note name stays hidden — it's only revealed after you nail it. Miss it and it stays hidden and comes back. Detection is pitch-class only by default — a guitar's written C sounds an octave lower, so exact-octave mode is off unless you turn it on. Play one clean note per beat and let it ring.
